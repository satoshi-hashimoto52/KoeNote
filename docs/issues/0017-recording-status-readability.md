# Issue #0017: 狭いウィンドウ幅で録音ステータスが読めない

- 状態: **解決**（Vitest 235 件 / Backend 106 件で検証）
- 起点コミット: `43fdd31`（0015 のコンパクト UI 導入以降）
- 種別: UI / 視認性
- 重要度: 中
- 影響: 320px 幅で常用する際の録音状態・進捗の把握

---

## 症状

320px 幅で録音ステータス領域の情報が潰れて読めない。

```text
録音    音        文        保存:transcript....
中     声:15:44:04  字:-
```

- 「録音中」が **「録音」「中」に折り返して**別々の語に見える
- 「音:16:06:28」「文字:16:06:27」のようにラベルを省略しすぎて意味が取れない
- 時刻と保存先を同じ 1 行へ詰め込んでいるため、すべてが途中で切れる
- `title` 属性のツールチップ（「最後に文字起こしが完了した時刻」）がカーソル位置に出るため、
  本体の文字情報へ大きく被る

原因は `.status-line` が `flex-wrap: nowrap` の 1 行にすべてを詰めていたこと。
フレックスアイテム内のテキストは折り返せるため、語の途中で割れていた。

---

## 修正

### 1. 録音状態を 1 つの表示にまとめる

`.status-state` として独立させ、`white-space: nowrap` で語が割れないようにした。
14px / 太字 / 前景色でこの領域内で最も目立たせ、状態ドット（録音中は赤の点滅）を付ける。
録音中のみ文字色も赤系にして、色でも判別できるようにする。

既存の `.status-pill` と同じトーン体系（`tone-idle` / `tone-recording` / `tone-done` /
`tone-error` / `tone-reconnecting`）を使い、雰囲気は維持する。

> 320px 以下では titlebar の `.status-pill` が CSS で隠れるため、
> ここが唯一の状態表示になる。

### 2. 時刻はラベルを省略しない（380px 以下で 2 行へ）

`音声` / `文字起こし` と全表記にし、`<dl>` のグリッドで幅に応じて自動的に切り替える。

| 幅 | レイアウト |
|---|---|
| 381px 以上 | `音声 16:06:28    文字起こし 16:06:27`（横並び・4 列） |
| **380px 以下** | 2 行（2 列）。ラベル列が揃うので値の位置も揃う |

**Breakpoint は 380px。** 360px では既に 2 行にする必要があり、
既存の 340px ブレークポイントとぶつからない値として選んだ。

### 3. 保存先を独立した行にする

時刻と同じ行へ詰め込まず、`.status-saved` として独立させる。
区切り線・11px・muted 色で視覚的優先度を一段下げる。
長いパスは ellipsis で省略し、`title` で全体を確認できる。

> フォルダを開くアイコンは追加していない。既存の「保存TXTを開く」と重複するため。

### 4. InfoTip（ツールチップの被りを解消）

`frontend/src/components/InfoTip.tsx` を新設。小さな「ⓘ」マークを対象項目の隣に置き、
**hover / キーボードフォーカス時だけ**説明を表示する。

表示位置は **ステータスカードの外側（上）でカード幅いっぱい**。
`.statusbar` を `position: relative` にし、`.infotip-body` を
`left: 8px; right: 8px; bottom: calc(100% + 6px)` で配置する。
カード幅に束縛されるため、狭いウィンドウでも画面外へはみ出さない。

## 検証

### 幅ごとの実測

| 幅 | 横スクロール | 状態表示 | 時刻 | 値の x 揃い |
|---|---|---|---|---|
| 960px | なし | `録音中`（1 行） | 横並び | — |
| 460px | なし | `録音中`（1 行） | 横並び | — |
| 400px | なし | `録音中`（1 行） | 横並び | — |
| 360px | なし | `録音中`（1 行） | **2 行** | ✅ |
| 320px | なし | `録音中`（1 行） | **2 行** | ✅ |
| 280px | なし | `録音中`（1 行） | **2 行** | ✅ |

280px まで文字の重なりなし。`scripts/responsive_check.cjs` も全 6 幅で横スクロールなし。

### ツールチップ（320px）

| 項目 | 結果 |
|---|---|
| 表示 | hover / focus 時のみ |
| 位置 | `x=19, right=301`（画面幅 320） |
| 画面外へはみ出さない | ✅ |
| カード本体に被らない | ✅（`bottom <= statusbar.top`） |

### 320x530 での縦の収まり

0017 で録音状態を独立行にしたぶん、狭幅では主要ボタンが折り返し位置より下へ出た。
文字サイズと入力欄の高さは変えず、`@media (max-width: 380px)` で余白のみ詰めて回収した
（`.content { gap: 6px }`、`.statusbar { padding: 6px 12px }`、`.field { gap: 4px }`）。

| | 詰める前 | 詰めた後 |
|---|---|---|
| ボタン下端 / content 下端 | 520 / 502 | **484 / 502** |
| ボタン可視 | ❌ | **✅** |
