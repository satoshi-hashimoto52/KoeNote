# Issue #0015: 320px 幅を常用するためのコンパクト UI

- 状態: **解決**（Vitest 130 件 / Backend 103 件で検証）
- 起点コミット: `3ced1e7`
- 種別: enhancement（UI）
- 影響: ヘッダー / メインフォーム / 操作ボタン / ステータスパネル
- 前提: [#0009](0009-smaller-window-responsive.md) で `minWidth = 320` にした結果、320px 幅が常用対象になった

## 背景

320px 幅の目視確認で次が判明した。

- **macOS の traffic lights（左上 3 ボタン）と「BridgeLog」タイトルが重なる**
- 入力デバイス / モデル / 遅延モードがメイン画面を占有している
- 「文字起こし開始」と「停止」が別ボタンで場所を取る
- ステータス欄が複数行に散らばる

## 要件

### 1. ヘッダー

- タイトルを**水平方向中央**へ。traffic lights 領域に文字を置かない
- **右上に設定用の歯車ボタン**
- タイトル / traffic lights / 歯車が重ならない
- ヘッダー全体はドラッグ可能。歯車など操作要素は `-webkit-app-region: no-drag`
- 320px でもタイトルを省略しない。通常幅でも中央配置
- ヘッダー高さを不必要に大きくしない
- **狭幅では状態ピルをヘッダーから外す**（録音進捗パネルに同じ情報があるため二重表示しない）

### 2. 設定歯車

メイン画面から設定モーダルへ移す項目。

- 入力デバイス / モデル / 遅延モード

モーダル要件: 現在値を表示 / 保存とキャンセル / **保存時だけ反映** / キャンセルで元の値を維持 /
Escape で閉じる / 背景クリックでも未保存値は破棄 / フォーカスがモーダル内に留まる /
`aria-label` / 320px で見切れない / 横スクロールを発生させない。

**録音中は変更不可。** 歯車を無効化し、セッション状態を壊さない。
保存済みの設定キーと保存形式は変更しない。

### 3. 開始／停止ボタンの統合

状態で変化する 1 つのボタンにする。

| 状態 | ラベル | 色 | 押下 |
| --- | --- | --- | --- |
| 停止中 | 文字起こし開始 | 紫系 | 録音開始 |
| 録音中 | 文字起こし停止 | 赤系 | 通常停止 |
| 開始処理中 | 開始中… | — | disabled |
| 停止処理中 | 停止中… | — | disabled |

異常停止中は通常停止と混同しない。既存の異常ポップアップと復旧操作を維持し、
**単純に開始ボタンへ戻して異常状態を隠さない。**

### 4. 操作ボタンを狭幅で 1 行に

`[開始／停止] [クリア]` を 1 行に。
`grid-template-columns: minmax(0, 2fr) minmax(72px, 1fr)`。
同じ高さ / 不自然な改行なし / 320px で横スクロールなし。
「マイGPTを開く」は別の 1 行で維持。

### 5. メインフォームの 1 行中心レイアウト

残す項目: タイトル / マイGPT URL / 保存先 / 文字起こし / 録音進捗 /
開始停止＋クリア / マイGPTを開く / 診断ログ。

表示ラベルは短縮してよい（タイトル / マイGPT / 保存先）。
**`aria-label`・`title`・説明文では正式名称を維持する。**

```
[タイトル] [入力欄]
[マイGPT] [URL入力欄]
[保存先] [パス欄] [選択]
```

ラベル幅を固定しすぎない / 入力欄へ十分な幅 / `min-width: 0` /
URL と保存先は省略表示可 / `title` で完全な値 / 必須表示はタイトル行内 /
320px で 1 文字折り返しを起こさない / 通常幅で間延びさせない。

### 6. 文字起こし欄

[#0008](0008-resizable-transcript-height.md) の修正（専用ハンドル / preferred と effective の分離 /
勝手に縮まない / ウィンドウ追従 / 再起動復元）を壊さない。

### 7. ステータス・進捗パネル

情報は削除せず、行数を減らす。

```
1 行目: 00:00:00  入力: BlackHole
2 行目: レベルバー
3 行目: 待機中  音声:-  文字:-
```

長い値は省略表示し、`title` で完全な値を見せる。

## 受入条件

- 320px でタイトル / traffic lights / 歯車が重ならない
- 320px で操作ボタンが 1 行
- 320px で横スクロールが発生しない
- 設定モーダルが 320px で見切れない
- 録音中は設定を変更できない
- 開始／停止ボタンが状態どおりに変化し、処理中は連打できない
- 異常状態が通常停止として隠されない
- 通常幅のレイアウトが崩れない
- 0008 のリサイズと自動スクロールが動く

## 目視確認項目

**320px**: traffic lights とタイトルが重ならない / タイトル中央 / 歯車右上 /
設定モーダルが見切れない / フォームがコンパクト / 開始停止＋クリアが 1 行 /
文字起こし欄を伸縮できる / ステータス欄が読める / 横スクロールなし / 縦スクロールで全操作へ到達。

**通常幅**: タイトル中央 / モーダルが適切な大きさ / フォームが間延びしない / 主要操作の配置が崩れない。

### ヘッダー

`grid-template-columns: minmax(78px, 1fr) auto minmax(78px, 1fr)`。
左右を等幅にすることでタイトルがウィンドウ中央へ来る。左は traffic lights が収まる 78px を下限にした。
高さは 44px → **40px** に縮めた（増やしていない）。
`.titlebar-trail` の button と status-pill に `-webkit-app-region: no-drag`。
状態ピルは 520px 以下で `display: none`（録音進捗パネルに同じ情報がある）。

### 開始／停止の統合

`resolveRecordButton` が状態を解決する。優先順位は 停止処理中 → 開始処理中 → 録音中 → 異常 → 停止中。

**異常時に開始ボタンへ戻さない。** 録音が続いていれば「文字起こし停止」、
録音が止まっていても「停止して保存」を出し、異常ポップアップ側の復旧操作を残す。

開始処理中は `starting` フラグ（`startRecording` の `finally` で解除）で「開始中…」+ disabled。

### フォーム

`.field-row` は `minmax(56px, auto) minmax(0, 1fr) auto` の 3 列。
表示ラベルは タイトル / マイGPT / 保存先 に短縮し、
**`aria-label` と `title` には正式名称（会議／セミナータイトル、マイGPTのURL、文字起こしファイル保存先）を維持**した。
URL と保存先は `title` に現在値を入れ、省略表示でも完全な値を確認できる。

### ステータス

3 行構成（`00:00:00 入力:…` / レベルバー / `状態 音声:… 文字:… 保存:…`）。
長い値は `.ellipsis` で省略し `title` に完全な値を入れた。**情報は削除していない。**

## 最終仕様（2026-08-29）

### ウィンドウ

| 項目 | 値 |
| --- | --- |
| 起動時サイズ | **320 × 530** |
| 最小サイズ | **320 × 480** |
| 実測外寸 | 320 × 530（`titleBarStyle: 'hiddenInset'` のため外寸＝内寸、差 0px） |

初期サイズだけを変更し、手動での拡大・縮小は従来どおり。
`setBounds` / `getBounds` などのサイズ永続化処理は存在せず、
設定ファイルにもウィンドウ関連キーはないため、保存値が初期サイズを上書きすることはない。

320 × 530 で **タイトル → 文字起こし欄 → 状態欄 → 3 ボタン → 診断ログが 1 画面に収まる**
（文字起こし欄 180px 時。ボタン bottom 456 / 診断ログ bottom 510 ≤ 530、縦スクロール不要）。

### ヘッダー

- `grid-template-columns: minmax(78px, 1fr) auto minmax(78px, 1fr)` で**タイトルを中央**に
  （左右等幅。左は traffic lights 用に 78px を下限）
- **右上に設定ボタン**。ボタン領域 32×32、アイコンは 18×18 のインライン SVG（`GearIcon.tsx`）、
  線幅 1.9、右端余白 7px、ヘッダー高 40px
- hover / active / focus-visible（紫系 2px リング）/ disabled（`opacity: 0.35`）
- ヘッダー全体は `-webkit-app-region: drag`、操作要素は `no-drag`
- 520px 以下では状態ピルを非表示（録音進捗パネルに同じ情報がある）
- 実測: 960 / 460 / 400 / 360 / 320 / 280px すべてで **重なりなし・中央ずれ 0〜4px**

### 設定モーダル（5 項目）

マイGPTのURL / 文字起こしファイル保存先（＋選択ボタン）/ 入力デバイス / モデル / 遅延モード。

- 5 項目をひとまとまりの下書きとして扱い、**保存を押したときだけ反映**
- キャンセル / Escape / 背景クリックで破棄。フォーカストラップあり
- 保存キーと形式は既存のまま（`gptUrl` / `saveFolder` / `deviceId` / `model` / `delayMode`）
- URL は前後空白を trim し、**既存の許可ドメイン（chatgpt.com / chat.openai.com、https のみ）を維持**。
  空・不正・許可外は保存不可でエラーを入力欄付近に表示
- 保存先は空・存在しないパスを保存不可（既存の `pathExists` を利用）。
  **フォルダ選択直後には保存せず下書きのみ更新**。選択をキャンセルした場合は下書きを変えない
- 変更がなければ書き込まない。録音中は歯車を無効化し、保存しても現在値のまま
- 320 × 530 での実測: 296 × 479（top 25 / bottom 505）で**見切れなし**。
  さらに小さい高さでは `max-height: calc(100vh - 24px)` + `overflow-y: auto` で内部スクロール

### 操作ボタン（3 つを 1 行）

`grid-template-columns: minmax(0, 1.3fr) minmax(64px, 0.9fr) minmax(78px, 1.1fr)`

| 状態 | 表示 | 色 | aria-label / title |
| --- | --- | --- | --- |
| 停止中 | 開始 | 紫 | 文字起こしを開始 |
| 録音中 | 停止 | 赤 | 文字起こしを停止 |
| 開始処理中 | 開始中… | 紫 / disabled | 文字起こしを開始しています |
| 停止処理中 | 停止中… | 赤 / disabled | 文字起こしを停止しています |
| 異常（録音中） | 停止 | 赤 | 文字起こしを停止して保存（異常が発生しています） |
| 異常（録音停止） | 停止して保存 | 赤 | 異常が発生しています。録音を終了して保存 |

**異常状態を通常待機（「開始」）として隠さない。**
クリアは中立色、マイGPT は紫アウトライン（`btn-accent`）。表示は「マイGPT」へ短縮し、
`aria-label` / `title` は「マイGPTをGoogle Chromeで開く」。0006 の動作（Chrome →
既定ブラウザのフォールバック / 許可 URL 検証 / 連打防止 / エラー表示）はすべて維持。

320px の実測: **開始 113px / クリア 79px / マイGPT 96px**、間隔 6px、高さ 42px、同一行。
`font-size` は 12〜13px、`white-space: nowrap` で 1 文字折り返しなし。

### メインフォーム

タイトル行のみ（マイGPT URL 行と保存先行は設定モーダルへ移動）。
表示ラベルは短縮し、`aria-label` / `title` に正式名称を残す。

### 文字起こし欄

- 専用ハンドルで手動伸縮。`preferredHeight`（保存）と `effectiveHeight`（表示）を分離（[#0008](0008-resizable-transcript-height.md)）
- 高さは `transcriptHeight` キーへ保存し、次回起動時に復元
- 本文 **13px** / `line-height` 1.65 / `font-weight` 400。
  変数 `--font-transcript` / `--font-transcript-line` で管理
- 確定文・暫定文・プレースホルダー・`[中断]` 行に適用。色と装飾の区別は維持
- 保存される `transcript.txt` とコピー内容には影響しない

### 診断ログ

`summary:focus` は `outline: none`（マウス操作で太い枠を残さない）、
`summary:focus-visible` で紫系 2px リング + `outline-offset: 2px`。
